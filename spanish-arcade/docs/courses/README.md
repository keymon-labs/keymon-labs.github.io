# Course notes

One folder per course, named like the course id in `courses/<courseId>/course.json`. It holds **our own paraphrased notes** about a course book (topics, grammar points, kinds of exercise) and nothing from the book itself. How the notes become units: [../PIPELINE.md](../PIPELINE.md).

| Folder | What |
|---|---|
| [a1s1/](a1s1/README.md) | The first course (A1, first term). Notes per book unit: `u1.md`, `u2.md`, `u3.md` |
| [_template/](_template/) | Copy-from templates for a new course README and for one section's notes |

Only `.md` files live here (no images, PDFs or audio).
