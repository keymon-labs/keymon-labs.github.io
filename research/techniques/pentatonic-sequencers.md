# Pentatonic sequencers

- A five-note scale has no harsh intervals, so any pattern tapped in sounds consonant: beginners explore with no wrong notes.
- Grid layout: rows are scale notes (often repeated across octaves), columns are beats, a playhead sweeps and plays lit cells.
- Add feedback (particles, glow), loop length and a shareable pattern.
- Related no-wrong-note ideas: keyboards mapped to a scale (aQWERTYon), Ableton Push's scale mode.
- Real examples: ToneMatrix Redux (GPL), Pocket Sequencer, MusicToy, noktone, audio-grid.
