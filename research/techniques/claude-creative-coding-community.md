# Claude and creative coding community

- Skills are plain SKILL.md files, so they work across Claude Code, Codex, Cursor and others, and are shared through directories (skills.sh, claudemarketplaces, mcpmarket, tessl, vibehackers).
- Official: Anthropic's `algorithmic-art` (p5.js); its repo is very widely starred.
- Community: p5.js pipelines, several d3 skills, "Claude Code for Processing and p5.js" guides, and showcase builds such as a Claude-Code-made music visualiser tool.
- Quality varies (registry scores around 40 to 70%), and a skill is instructions the model obeys, so read it first.
- Not found: a distinct community around stereoDrift or jfire.io style music visuals with Claude. Those look like individual authors.
