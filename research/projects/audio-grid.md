# audio-grid

A 2013 port of Tone Matrix. MIT per a catalogue listing (not the licence file). Built with timbre.js, subcollider.js, d3, jQuery, Bootstrap and JsMidGen (MIDI file output), so it can export patterns as MIDI. Other re-creations seen: noktone (HTML5 Web Audio, inspired by Tone Matrix and the Yamaha Tenori-On) and MusicToy (a minimalist grid sequencer with drum samples and minor pentatonic notes).
