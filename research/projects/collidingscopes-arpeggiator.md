# Arpeggiator (collidingScopes)

Hand-controlled arpeggiator, drum machine and audio-reactive visualiser. Needs WebGL and camera access. The README credits Rosebud AI.

## Learn
- The mapping (height to pitch, pinch to volume, fingers to pattern) is a clean template for hands-in-the-air music toys.
