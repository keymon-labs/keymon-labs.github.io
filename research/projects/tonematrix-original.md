# ToneMatrix (Audiotool)

Created by Andre Michelle in 2009 as a Flash toy: a simple sine-wave synthesiser triggered by a 16-step sequencer, where each step pushes on a wave map so the visuals move. The maker said there were no sources to share. It lives on as a ToneMatrix device in Audiotool, the browser studio: a 16x16 grid with groove controls and optional MIDI routing. Audiotool's own page says it is free to use; terms not read.
