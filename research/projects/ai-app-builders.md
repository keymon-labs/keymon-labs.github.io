# General AI app builders

A collection, not one product. Prices are entry plans seen in 2026 comparisons and change quickly.
- **Lovable** (from $25 a month): React, TypeScript and Tailwind with Supabase; two-way GitHub sync, so you own the code.
- **Bolt.new** (from $25): in-browser, several frameworks, Expo for mobile, GitHub export.
- **Replit** (from $20 to $25): full IDE plus agent, multi-language, built-in hosting and database; most infrastructure coupling.
- **v0 by Vercel** (free credits, then from $20): React and Next.js interfaces, UI only.
- **Base44**: business apps with backend and auth built in.
- **Cursor, Cline (Apache-2.0, any provider key or local models), Aider (free)**: editors and agents rather than hosts.

All three of Lovable, Bolt and Replit produce portable code. Several offer GitHub sync, which is the same open-files shape as this repo.
