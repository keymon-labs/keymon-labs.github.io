# Music Blocks

"A musical microworld": a visual programming language and tools for exploring musical and mathematical ideas, a fork of Turtle Blocks JS started by Walter Bender and now maintained by Sugar Labs (about 915 stars, 12k commits). Rhythm and melody blocks, a graphics (turtle) mode, a lesson-plan folder and translations. Runs in the browser; repo also has npm, Docker and Electron entry points. The old walterbender.github.io page is only a loader that points to Planet; the live site is musicblocks.sugarlabs.org.

## Learn
- The Scratch-for-music idea: kids snap blocks to make patterns, so the programming is the music lesson.
- Teaches rhythm, melody and maths together, which matches our rhythm tiles.
- Spanish was not confirmed from the repo page (translations exist).
