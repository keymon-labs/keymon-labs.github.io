# OhMyGame

The open alternative to Rosebud: no per-run credits, you connect your own provider (40+) or a coding agent you already use (Claude Code, Codex, OpenCode). It works the other way too: the canvas, media generation and playtesting are reachable from your agent over MCP.

## Capabilities
- Game canvas, asset and media generation, automated playtesting, plugins (Godot, Unity, Unreal, Blender, Aseprite, Tiled, mini-game platforms).
- Web games with Phaser, Three.js or React Three Fiber are the recommended start. Web games can be multiplayer with no server of your own. Interactive stories and any other engine also work.
- Apache-2.0, with the name and logo excluded. Build needs Bun and Node.

## Learn
- The "bring your own agent plus MCP" shape is close to how this repo is built with Claude.
