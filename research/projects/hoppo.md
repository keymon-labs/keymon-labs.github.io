# Hoppo

Free for personal and educational use, paid licence for commercial use. Games: movement (Bubble Pop, Ninja Strike, Floor is Lava, Dodge), learning (Letter Trace, Math Catcher, Count in Order) and creative (Magic Paint, Grow a Pet). Static HTML pages, tracking library not named. Says video stays on the device.

## Learn
- Three input modes (hand camera, move camera, touch) keep it playable on any device.
- A no-camera class mode, a parent view and a performance mode are cheap features that matter.
