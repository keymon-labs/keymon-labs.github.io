# gettothechopin portfolio

Static page ("I experiment with computer vision, games, and quirky web projects"). Same creator as [collidingScopes](../authors/collidingscopes.md): the GitHub profile links here, and the project list includes Stereo Drift, Colliding Scopes, Particular Drift and Video-to-ASCII. The cards are rendered by script, so the list below comes from the repo's `main.js`, not from opening each project. The links were not captured: open the portfolio.

## Projects listed
- Games and play: **Acrobatic Arcade** (free web games using computer vision and hand tracking), **Am I A Banana?** (real-time banana detection game), **Red Panda Vibes** (panda exploration web game for a 2025 game jam).
- 3D and gestures: **3D Model Playground** (voice and hand gestures), **Threejs Shape Creator** (shapes by hand gestures).
- Animation and art tools: **Liquid Shape Distortions**, **Liquid Logo**, **Particular Drift**, **Video-to-ASCII**, **Shape Shimmer**, **Image Mage**, **Colliding Scopes** (photo to kaleidoscope), **Video-to-Pixel-Art**, **Shades Drawn**.
- Music: **[Stereo Drift](stereodrift.md)** (music visualiser).
- Other: **Fun With Computer Vision** (20+ projects and tutorials, see [fun-with-computer-vision.md](fun-with-computer-vision.md)) and a personal-finance tools site.

## Learn
- Acrobatic Arcade is the closest match to the movement-games theme: look at it next (URL not found in my search).

- Playful framing (a banana detector, a panda explorer) makes computer vision approachable for young players.
