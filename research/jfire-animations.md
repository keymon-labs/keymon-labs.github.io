# jfire.io animations: a daily generative-animation series

- Live: <https://jfire.io/animations/>

A gallery of about 70 small animations, one per day, dated from 2014-12-20 to 2016-03-05 (a run of daily pieces through early 2015, then a few later ones). Each is shown as a thumbnail image that links to its own animation.

## What was verified
Only the gallery page was read, and it is thumbnails with file names by date. No author name, description, licence or source link was visible, and the individual animations and their code were not opened. Treat everything else as unknown until checked.

## Link to Stereo Drift
Per the owner, the [Stereo Drift](stereodrift.md) visualisation styles are inspired by this series. Not confirmed from either site.

## Learn / try
- The "one small animation per day" format is a good way to build a library of visual styles quickly: each piece is one idea, one palette, one motion.
- Many tiny styles, one common interface (draw a frame from time and audio levels) is the structure that lets a visualiser hold dozens of looks.
- Open a few animations, view source, and note which techniques recur (canvas or SVG, noise, easing, palettes).
