Build your own labs site

Publish small web apps for free by chatting with Claude. No coding needed. Setup takes about 30 minutes on a computer; after that you can work from your phone.

You need

  • A paid Claude plan (Pro or Max) for Claude Code in the cloud.
  • A free GitHub account. GitHub stores your code and hosts the site.

  1. Create a GitHub account

    Sign up at github.com/signup. Turn on two-factor authentication.

  2. Create an organization (optional)

    Keeps the site separate from your personal account. Go to github.com/organizations/plan and pick Free. Its name becomes your address: NAME.github.io. Skip this to use your username instead.

  3. Create the site repository

    At github.com/new: owner = your organization (or you), name exactly NAME.github.io, Public, tick Add a README file.

    Ref: Creating a GitHub Pages site

  4. Turn on GitHub Pages

    In the repository: Settings → Pages → Build and deployment → Source: GitHub Actions.

    Ref: Configuring a publishing source

  5. Connect Claude to GitHub

    Open claude.ai/code, sign in, choose Sign in with GitHub and approve. Then install the Claude GitHub App on your organization and give it access to the site repository.

    Ref: Get started with Claude Code in the cloud

  6. Ask Claude to set up the site

    At claude.ai/code, pick your repository, paste this and send:

    Set up this repository as a GitHub Pages site for small web apps, copying the setup of github.com/keymon-labs/keymon-labs.github.io (CLAUDE.md, vite.config.js, package.json, .github/workflows/deploy.yml, the landing page and .claude/skills), with my site name instead of keymon-labs and no apps yet. The repo is public: never commit personal data, API keys or copyrighted material. Run the tests and the build, then merge to main.

    Claude works on a branch. When it's done, open the pull request it made and press Merge on GitHub, or ask Claude to merge it.

  7. Check it's live

    On GitHub, the Actions tab should show a green run. Then open https://NAME.github.io. The first deploy can take a couple of minutes.

  8. Make your first app

    Start a new session on the repository and describe what you want, for example:

    • “Add a times-tables quiz for a 7-year-old, big buttons, works on a phone.”
    • “Add a packing-list app that remembers my lists on this device.”

    Merge, wait for the green run, and it appears at NAME.github.io/APP/. From your phone, use the Code tab in the Claude app.

  9. Keep it safe

    • Everything in a public repository is visible forever: no names of children, photos, addresses or passwords.
    • Never paste API keys or tokens into the code.
    • Don't use copyrighted characters, logos or music. Ideas are fine; their art isn't.
    • Add a licence so people know what they may do with your work (choosealicense.com).

Optional: run apps inside Claude

Apps that use AI can also run inside Claude, on each visitor's own Claude account, with no API keys. Ask Claude to follow the labs-claude-loader skill, and read the security notes first.

If something goes wrong

  • Site shows 404: the repository name isn't exactly NAME.github.io, or Pages source isn't “GitHub Actions”.
  • Red run in Actions: open it, copy the error, paste it to Claude and ask it to fix it.
  • Claude can't see the repository: install the Claude GitHub App on the organization and include the repository.
  • Old version still showing: reload the page twice; installed apps update on the next open.
